# odin-recipes

## Description
This project is a basic recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum. The primary goal of this project is to practice fundamental HTML, relative file paths and Git version control before introducing css styling.

## Live Demo
[View Live Site](https://www.google.lk)

## Skills Demonstrated
* Structuring document skeletons with HTML boilerplate
* Formatting text hierarchies using headings (`<h1>` to `<h3>`) and paragraphs (`<p>`)
* Working with lists: unordered (`<ul>`) for ingredients and ordered (`<ol>`) for instructions
* Embedding local images with descriptive `alt` text
* Navigating between local directory files using relative links (`<a href="...">`)
* Practicing staged Git commits and hosting via GitHub Pages
